# Exercise 2 — Enterprise Developer Portfolio

A lightweight, accessible portfolio built with semantic HTML, CSS design tokens, responsive Grid, and a persistent light/dark theme.

## Run locally

From this directory, start a static web server:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000` in a browser. The project has no package or build step.

## Project files

- `index.html` contains the semantic portfolio content.
- `css/style.css` contains the theme tokens, reset, and responsive layout.
- `js/theme.js` controls and persists the theme selection.
- `TASK_DECOMPOSITION.md` records the implementation milestones.
