# HW3 implementation steps

## Step 1 - Requirements and architecture
React + TypeScript frontend, Express API and PostgreSQL inventory authority.
Countdown uses Date.now() deadlines and requestAnimationFrame cleanup.
Reservations expire on the backend; checkout is idempotent.
Stock is decremented with an atomic conditional SQL update.
At least eight real Conventional Commits and an AI failure audit are required.
This is a local demo without real payments or authentication.
